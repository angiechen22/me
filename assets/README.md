# Assets

Use this folder for background images and visual collateral for each experience section.

Suggested layout:

```text
assets/
  experience/
    microsoft-update/
    windows-client/
    autopatch/
    rice/
```

Recommended file types:
- SVG for logos and simple vector illustrations
- PNG/JPG for photos or more detailed artwork
- Keep files lightweight and transparent where possible

Suggested naming:
- microsoft-update-bg.svg
- windows-client-bg.svg
- autopatch-bg.svg
- rice-bg.svg

When you add assets, I can wire them into the relevant experience cards as subtle, low-opacity background art behind the content.
